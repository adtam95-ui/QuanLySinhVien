# ĐỒ ÁN QUẢN LÝ SINH VIÊN

## Công nghệ sử dụng
- Java Swing (Apache NetBeans)
- SQL Server 2025
- JDBC

## Chức năng
- Đăng nhập, đăng xuất
- Thêm, sửa, xóa, tìm kiếm sinh viên
- Quản lý điểm sinh viên

## Tài khoản đăng nhập thử
- Tài khoản: admin
- Mật khẩu: 123456

## Hướng dẫn chạy
1. Chạy file QuanLySinhVien.sql trong SQL Server để tạo cơ sở dữ liệu.
2. Mở project bằng Apache NetBeans.
3. Cấu hình kết nối SQL Server phù hợp với máy.
4. Chạy chương trình và đăng nhập bằng tài khoản demo.
